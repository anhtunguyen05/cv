# AI Workflow (Compatibility Entry Point)

AI-assisted revision is post-MVP. Its permanent guardrails are in
[architecture/overview.md](architecture/overview.md),
[standards/security.md](standards/security.md),
[standards/observability.md](standards/observability.md), and
[standards/reliability.md](standards/reliability.md).

AI returns evidence-bound proposals through an application contract; it never
writes trusted state and every Patch requires explicit user approval.
