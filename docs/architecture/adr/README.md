# Architecture Decision Record Policy

The initiative architecture spine is the current decision register. Its `AD-*`
identifiers are stable and may be referenced by standards, epics, stories, and
code review.

Create an ADR here only when a later decision changes a durable implementation
choice after it has been adopted. An ADR must state the decision, the affected
AD IDs, effective date, supersession relation, and migration consequences. Do
not copy full standards or story behavior into an ADR.
