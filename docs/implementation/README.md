# Legacy Implementation Work Packages

The phase packages in this folder are retained as historical planning
references. They are not part of the current BMAD workflow and must not be used
to select, order, assign, or break down current stories.

Current planning authority is:

- `_bmad-output/planning-artifacts/epics.md` for canonical epics, stories, and
  acceptance criteria;
- `_bmad-output/implementation-artifacts/sprint-status.yaml` for story
  lifecycle state; and
- `_bmad-output/implementation-artifacts/<story-key>.md` for each story's
  BMAD analysis and task breakdown.

Follow [`../story-execution.md`](../story-execution.md) for current story
breakdown. Do not update phase issue checkboxes or infer implementation status
from these folders.
