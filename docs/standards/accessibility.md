# Accessibility and Interaction-State Standard

References: NFR-3.

- **A11Y-STD-001:** Every product flow defines loading, empty, validation,
  authorization, retryable failure, and terminal failure states before UI work
  is accepted.
- **A11Y-STD-002:** Core create, edit, compare, preview, and export actions are
  keyboard usable; controls have accessible names and validation messages are
  programmatically associated with their controls.
- **A11Y-STD-003:** Do not treat a successful HTTP response as sufficient UI
  verification. Critical journeys require browser checks of their state and
  keyboard behavior under the testing standard.
